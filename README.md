Deskripsi singkat repository: Repository (repo) adalah tempat penyimpanan sebuah proyek beserta seluruh riwayat perubahannya. Isinya berupa file proyek (kode, gambar, dokumen) dan data Git di folder .git yang mencatat siapa mengubah apa dan kapan. Repo bisa ada di komputer lokal maupun online di GitHub.

Kegunaan:
> Menyimpan semua file proyek di satu tempat yang terorganisir
> Melacak riwayat perubahan, sehingga bisa kembali ke versi sebelumnya jika ada kesalahan
> Memudahkan kolaborasi, karena banyak orang bisa bekerja di proyek yang sama
> Menjadi backup di GitHub, sehingga kode tidak hilang kalau komputer bermasalah

FROM AI TO GITHUB - Nugi Farhan

Prompt adalah instruksi atau masukan yang Anda berikan kepada model untuk mendapatkan hasil tertentu.

Tujuan Sesi:
> Menjelaskan bagaimana prompt AI yang lebih spesifik menghasilkan hasil yang lebih baik
> Mengidentifikasi repository, commit, branch, dan pull request
> Membedakan Git dan GitHub
> Melakukan version controlling

Definisi: 
Prompt = instruksi/masukan ke model AI untuk mendapat hasil tertentu (bisa pertanyaan, kata kunci, instruksi rumit, atau potongan kode)
Prompt engineering = cara merancang instruksi agar jawaban AI tepat, relevan, dan layak dipakai

Context is key: 
Tanpa konteks: “Create student task planner” → hasil umum dan tidak terarah
Dengan konteks: ada tujuan, requirements, constraints, dan output yang jelas → hasil lebih sesuai 

Prompt Engineering:
Prompt yang spesifik dan punya konteks menghasilkan jawaban AI yang lebih tepat. 
Struktur yang baik: Role, Task, Context, Format.

Git vs GitHub:
Git = alat version control di komputer lokal. 
GitHub = platform online untuk menyimpan repo Git dan berkolaborasi.

Git Workflow:
Perubahan bergerak dari Working directory → Staging area → Repository lewat add lalu commit.

Command Penting:
git init 
git add .
git commit -m
lalu git push / git pull untuk sinkron dengan GitHub.
